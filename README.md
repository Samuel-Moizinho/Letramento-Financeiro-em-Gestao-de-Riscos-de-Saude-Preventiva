# SaúdePlanejada 🏥💡

**SaúdePlanejada** é uma aplicação web interativa desenvolvida como projeto de extensão universitária do curso de Análise e Desenvolvimento de Sistemas. O foco do projeto é promover o **letramento financeiro e a gestão de riscos em saúde preventiva**, alinhando-se ao Objetivo de Desenvolvimento Sustentável (ODS) 3 da ONU: Saúde e Bem-Estar.

A solução traduz normativas complexas da Agência Nacional de Saúde Suplementar (ANS) e tabelas de custos médicos em ferramentas visuais acessíveis, capacitando os usuários a evitarem despesas médicas imprevistas e a compreenderem seus direitos pré-contratuais.

## 🚀 Funcionalidades Principais

*   **Simulador de Impacto Financeiro:** Motor lógico que calcula estimativas de custos de emergências médicas particulares com base em tabelas de referência, evidenciando o risco do não planejamento.
*   **Checklist Dinâmico Pré-Contrato:** Algoritmo que cruza o perfil do usuário com as regras da ANS para gerar recomendações personalizadas de modalidades de planos de saúde e exibir os prazos máximos de carência legais.
*   **Glossário Interativo:** Sistema de busca para tradução de termos técnicos e jurídicos da saúde suplementar.
*   **Avaliação de Impacto:** Módulo de coleta de métricas comunitárias para acompanhamento de resultados do projeto de extensão.

## 🛠️ Tecnologias e Ferramentas

*   **Front-end:** HTML5, CSS3, JavaScript (ES6+).
*   **IA & Lógica de Negócios:** Aplicação de Inteligência Artificial Generativa e engenharia de prompt para mapeamento estruturado das regras de negócio (resoluções da ANS) e aceleração da codificação das lógicas do simulador.
*   **Versionamento e Deploy:** Git, GitHub, GitHub Pages.
